# 清风连接（Qingfeng Link）

免 root、免电脑的安卓小工具：在手机上**一键开启 adb tcpip 5555**，方便本机直接运行和调试脚本。

- 适用：Android 11（API 30）及以上
- 当前版本：v1.2.0（约 2.5MB）

> ⚠️ **免责声明**：本工具仅用于**在自有设备上**便捷开启无线调试。开启 5555 后可本机运行和调试脚本，用毕建议关闭（开发者选项关闭无线调试/重启手机）。请勿用于任何未经授权的设备。

## 功能特性

- **一键开启 adb tcpip 5555**：点一下，本机 adbd 即监听 5555 端口
- **零通道自举**：即使「无线调试」被系统关掉、5555 也没监听，App 也能自动把无线调试拉起来，全程免 root、免电脑
- **密钥持久化**：配对一次后重启手机、重启 App 都无需重新配对

## 使用步骤

### 首次（约 1 分钟）

1. 手机：设置 → 开发者选项 → 开启「USB 调试」和「无线调试」
2. 打开 App，点「打开无线调试设置」→ 点「**使用配对码配对设备**」（建议分屏，对话框离开设置页会自动关闭）
3. App 会自动填入配对端口，输入屏幕上的 6 位配对码 → 点「开始配对」
4. 点「**一键开启ADB 5555**」。首次连接时手机屏会弹授权，点「始终允许」。如无法开启，可等待 30 秒后重试或重启 App

### 日常使用

每次重启手机后，打开 App 点「一键开启ADB 5555」即可（无线调试会自动恢复；即便没有，App 也会自举拉起）。

### 本机调试

```bash
adb connect 127.0.0.1:5555   # 首次连接时手机屏会弹授权，点「始终允许」
```

## 兼容性说明

- 配对对话框一旦离开前台就会关闭，首次配对建议使用分屏
- 系统「允许在此网络上进行无线调试吗？」弹框需点「始终允许」
